# v1.21: Batch Complete Tasks

## Goal

打通"规划 → 执行 → 标记完成 → 复盘"闭环的最后一环：批量、可靠、可验证地完成或取消完成任务。

## Contract

新增工具 `batch_complete_tasks`：

```typescript
interface BatchCompleteTasksParams {
  items: Array<{
    taskId: string;
    action: 'complete' | 'incomplete';
    completionDate?: string; // ISO, only with action=complete
  }>;
}
```

- 最多 100 项，拒绝重复 ID 与未知字段。
- `completionDate` 省略时用当前时间。
- 不做 `dropped`、不做筛选式批量、不暴露预览或原子开关。
- `edit_item` 的单任务 `newStatus` 保持不变。

## Transaction & Verification

```
items → Schema 预检 → 解析全部稳定 ID → 记录原完成状态 → 逐项 markComplete/markIncomplete
  → 读回验证状态与完成时间 → 返回逐项结果
  ↓ 异常或不匹配
恢复原状态（含删除重复任务新实例）
```

**预检零写入：**

- 所有 ID 存在
- `incomplete` 目标当前已完成，`complete` 目标当前未完成（幂等项标记 `unchanged`）
- `completionDate` 是合法 ISO 日期

**重复任务：**

官方 `markComplete(date)` 会克隆并生成下一个实例。工具如实返回 `generatedTaskId` 与 `nextOccurrence`，不抑制。

**恢复语义：**

写入异常或读回不一致时，按逆序恢复已改动项的原状态，删除重复任务新实例。无法确认恢复时返回受影响 ID。

**错误码：**

- `INVALID_COMPLETION`
- `COMPLETION_FAILED_RESTORED`
- `COMPLETION_VERIFICATION_FAILED_RESTORED`
- `COMPLETION_RESTORE_UNCONFIRMED`
